# KOLONGO Attendance System

A responsive attendance management system for KOLONGO TANZANIA LIMITED, designed to work on desktop and mobile browsers and ready for deployment to Firebase or other hosting providers.

## Features

- Employee time-in and time-out
- Admin login and account creation
- Employee registration and editing
- Attendance report table
- CSV export
- PDF print support
- Delete employee and attendance records
- Responsive design for laptop and mobile
- Firestore-ready online storage

## Live deployment

This project is designed to work with Firebase Firestore and can be deployed to Firebase Hosting or Vercel with minimal changes.

## Local run

Open `index.html` in a browser. For full online functionality, configure Firebase credentials in the `index.html` script.
